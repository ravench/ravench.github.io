# App pages

Support and privacy pages for the App Store and Google Play listings (GitHub Pages, branch main, folder /).
Each page holds all its app's languages (de, en, fr, it; Kaliberfinder's and Kaliberkatalog's also es); `lang.js` shows the visitor's (German by default), `#en` etc. pick one.

- `kaliberfinder/` — Support URL
- `kaliberfinder/privacy.html` — Privacy Policy URL
- `schiesstagebuch/` — Support URL
- `schiesstagebuch/privacy.html` — Privacy Policy URL
- `kaliberkatalog/` — Google Play: Kaliberkatalog's support page (Android)
- `kaliberkatalog/privacy.html` — Google Play: privacy policy

Contact address: appsupport@giotta.ch.
Custom domain later: add a `CNAME` file (e.g. `apps.giotta.ch`) and the DNS record GitHub Pages asks for.
